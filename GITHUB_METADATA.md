# GitHub Repository Metadata

## Suggested repository name
`chinese-cultural-names-english`

## Repository title
Chinese Cultural Names in English: Reproducibility Data and R Code

## Short description
Reproducibility repository for a 1800–2022 study of Chinese cultural names in English, including curated Ngram-derived data, independent coding and adjudication files, historical-spelling audits, R scripts, final model outputs, and figures.
